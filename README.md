# priyanshuupadhyay/tap

Homebrew formulae for [yelo](https://github.com/PriyanshuUpadhyay/yelo): Claude and Codex
account profiles with a local usage HUD for macOS.

```sh
brew tap priyanshuupadhyay/tap
brew trust --formula priyanshuupadhyay/tap/yelo   # Homebrew 6 or newer
brew install priyanshuupadhyay/tap/yelo
```

See the [project README](https://github.com/PriyanshuUpadhyay/yelo#readme) for setup.
