# priyanshuupadhyay/tap

Homebrew formulae for [swarm](https://github.com/PriyanshuUpadhyay/swarm): a message bus and pane
control for a tree of agent CLIs, with the web UI inside the binary.

```sh
brew tap priyanshuupadhyay/tap
brew trust --formula priyanshuupadhyay/tap/swarm   # Homebrew 6 or newer
brew install priyanshuupadhyay/tap/swarm
```

See the [project README](https://github.com/PriyanshuUpadhyay/swarm#readme) for setup.
